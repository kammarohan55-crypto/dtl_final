# ============================================================================
# ENDPOINT DOCUMENTATION
# ============================================================================
#
# 1. POST /api/progress/save
#    Save a quiz attempt and update progress tracking.
#
#    Request:
#      - module_id (string, required): Unique module identifier
#      - score (number, required): Quiz score 0-100
#      - subject (string, optional): Subject name (e.g., "mathematics")
#      - level (string, optional): Level (e.g., "beginner")
#      - time_taken (number, optional): Seconds spent on quiz
#
#    Response (200):
#      - success: true/false
#      - module_id: The module ID
#      - status: "in_progress" (score < 70) or "completed" (score >= 70)
#      - attempts: Total number of attempts
#      - best_score: Highest score achieved
#      - last_score: Most recent score
#      - last_attempted_at: ISO 8601 timestamp
#
#
# 2. GET /api/progress
#    Retrieve all progress records.
#
#    Response (200):
#      - success: true/false
#      - total_modules_attempted: Number of modules with records
#      - completed_count: Number of completed modules (status="completed")
#      - modules: Object with module_id keys containing full records
#
#
# 3. GET /api/progress/<module_id>
#    Retrieve progress for a specific module.
#
#    Response (200):
#      - success: true/false
#      - module_id: The requested module ID
#      - status: Current status
#      - attempts: Total attempts
#      - best_score: Highest score
#      - last_score: Most recent score
#      - last_attempted_at: ISO 8601 timestamp
#      - history: Array of all attempts with scores and timestamps
#
#    Response (404):
#      - success: false
#      - error: "No progress record found for module: {module_id}"
#
#
# ============================================================================
# IMPLEMENTATION NOTES
# ============================================================================
#
# PASS_THRESHOLD:
#   Set to 70 (exposed as a constant in app.py)
#   Change PASS_THRESHOLD = 70 at the top of backend/app.py to adjust
#
# File Safety:
#   - Uses PROGRESS_LOCK (threading.Lock) for concurrent access
#   - Atomic file writes via temporary file + rename
#   - Windows and Unix compatible
#
# Progress File Location:
#   {project_root}/user_progress.json
#   Example: c:/Users/Rohan/Desktop/dtl_2/user_progress.json
#
# Data Persistence:
#   All progress is stored in user_progress.json on disk
#   File persists between server restarts
#
# Status Logic:
#   - "in_progress": Module attempted but score < PASS_THRESHOLD
#   - "completed": Module score >= PASS_THRESHOLD
#   - Once "completed", status never downgrades to "in_progress"
#   - best_score only updates when new score exceeds current best
#
# Timestamp Format:
#   ISO 8601 UTC: "2026-01-23T10:30:00.123456+00:00"
#   Timezone: UTC (Z suffix)
#
# ============================================================================
